# Rust Player 0.4.0

Windows 10 and 11 · x64

## Library Desk

- Redesigned the player around a compact playlist sidebar, centered search, and an integrated window title bar.
- Switch between **Queue** and **Track** in the right panel. Track shows artwork, artist, album, and lyrics together.
- Press **Ctrl+K** to focus search. The playback bar includes a thin seek bar and a compact volume slider with mouse-wheel control.

## Play Queue

- See upcoming playlist tracks and their actual shuffle order.
- Right-click a song and choose **Add to Play Queue** to schedule it ahead of the playlist.
- Drag upcoming tracks to reorder them or use the context menu to move or remove them. Queue edits apply to the current session.

## Appearance

- Edit presets, colors, fonts, and backgrounds directly in **Settings → Appearance**.
- Preview changes live and save them with **Apply**.
- The Library Desk palette adds an olive accent. The header mark uses Guifx v2 Transports when installed locally.

## Download

Extract the Windows x64 ZIP and run `Rust-Player.exe`. The archive includes licensing and third-party notices. A SHA-256 checksum is available alongside it.
